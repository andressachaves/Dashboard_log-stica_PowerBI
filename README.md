# 📦 Dashboard de Logística — Power BI

Dashboard interativo desenvolvido em Power BI para análise de operações logísticas de uma empresa automotiva, com foco em performance de transportadoras e otimização de rotas.

## 📌 Contexto

A empresa realiza reuniões mensais com transportadoras contratadas e precisava de uma visão consolidada das operações. Este dashboard entrega insights estratégicos para tomada de decisão em tempo real.

## 🎯 Objetivos de Análise

- **OTD (On-Time Delivery):** Percentual de entregas realizadas dentro do prazo
- **Mapa de Rotas:** Visualização da malha logística para otimização de trajetos
- **Custo de Frete:** Acompanhamento e comparativo de custos por transportadora
- **Performance por Transportadora:** Ranking e análise comparativa de desempenho

## 📊 Principais Métricas

| KPI | Descrição |
|-----|-----------|
| OTD % | % de entregas no prazo |
| Volume por Rota | Quantidade de entregas por trajeto |
| Custo/kg | Custo de frete por quilograma transportado |
| Avaliação Transportadora | Score de desempenho por fornecedor |

## 🚀 Como Visualizar

1. Faça o download do arquivo `Projeto Logística BI.pbix`
2. Abra no **Power BI Desktop** (gratuito)
3. Atualize a fonte de dados apontando para o arquivo `Historico Transporte.xlsx`
